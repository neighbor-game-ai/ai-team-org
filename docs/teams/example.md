# Example team (charter)

Keep a charter to four short points. Replace this file with your own team's.

- **What we do**: build and look after the sign-up and login flow. The lead plans and reviews; members do the work (`scripts/member-launch.sh`).
- **Decisions by the human**: [example/decisions.md](example/decisions.md). Link to it; don't copy decisions here.
- **How members are started**: CONVENTIONS.md §6 (one brief per task in `example/tasks/`, then `member-launch.sh`).
- **Working with other teams**: ask the manager to merge and release (only the manager merges to the main branch). Ask the design team for screens; they ask us for API changes.
