# docs

- `WHY.md` / `WHY.ja.md` — why each rule exists
- `teams/<team>.md` — a team's charter (4 points)
- `teams/<team>/decisions.md` — the human's decisions and open questions
- `teams/<team>/tasks/*.md` — one brief per task; the first 3 lines are its state

Only the example team lives here. Your teams' docs live in the repo each team works on.
